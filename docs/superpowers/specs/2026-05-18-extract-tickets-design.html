extract-tickets Script Design

Date: 2026-05-18  |  Status: Approved

Problem

update-pr-description Step 2 requires Claude to scan branch name, PR title, PR body, and commit messages for ticket ID patterns, uppercase prefixes, deduplicate, and construct Monday.com URLs — all in its head, every run. This is deterministic text processing that should be a script.

Solution

A bash script extract-tickets.sh that takes a PR number or URL, fetches all relevant text from gh, extracts ticket IDs, and returns structured JSON.

Interface

~/.claude/skills/update-pr-description/extract-tickets.sh [<pr-number-or-url>]
  • Argument optional — auto-detects current branch's PR if omitted (same pattern as pr-comments.sh)
  • On success: JSON array on stdout
  • On error: {"error": "..."} on stderr, exit non-zero

Output

[
  {"id": "MOB-123", "url": "https://dimerhealth-cast.monday.com/item/MOB-123"},
  {"id": "ENG-456", "url": "https://dimerhealth-cast.monday.com/item/ENG-456"}
]

Returns [] when no tickets are found.

Extraction Logic

Sources

All four sources are concatenated into one text blob before extraction:

  1. Branch name (headRefName)
  2. PR title
  3. PR body
  4. All commit message headlines

Pattern

[A-Za-z]+-[0-9]+ — matched via grep -oE

Post-processing

  • Uppercase the alphabetic prefix (e.g. mob-123 → MOB-123)
  • Deduplicate
  • Sort

URL template

https://dimerhealth-cast.monday.com/item/<ID>

Skill Integration

File: update-pr-description/SKILL.md — Step 2 only

Replace the current manual scan instructions with:

Run ~/.claude/skills/update-pr-description/extract-tickets.sh [<number>] and use the JSON array output directly. If the array is empty, the Tickets section gets "None".

No other steps change.
