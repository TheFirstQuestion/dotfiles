Skill Script Tests Design

Date: 2026-05-18  |  Status: Approved

Problem

The skill bash scripts (extract-tickets.sh, pr-data.sh, pr-comments.sh) contain deterministic logic (jq transforms, regex extraction, flag resolution) with no automated tests. Regressions are caught only when a skill misbehaves in production.

Solution

A lightweight offline test suite: each skill gets a tests/test-skill.sh that tests its pure logic using inline JSON fixtures, and a central claude/run-tests.sh discovers and runs all of them.

File Structure

claude/
  run-tests.sh                              ← discovers + runs all test-skill.sh files
  skills/
    update-pr-description/
      tests/
        test-skill.sh                       ← tests extract-tickets.sh and pr-data.sh logic
    handle-pr-comments/
      tests/
        test-skill.sh                       ← tests pr-comments.sh logic

Runner: claude/run-tests.sh

Discovers every skills/*/tests/test-skill.sh, runs each, aggregates results, exits non-zero if any suite failed.

#!/usr/bin/env bash
set -euo pipefail
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
total_pass=0; total_fail=0

for test_file in "$SCRIPT_DIR"/skills/*/tests/test-skill.sh; do
  skill=$(basename "$(dirname "$(dirname "$test_file")")")
  echo "=== $skill ==="
  output=$(bash "$test_file"); status=$?
  echo "$output"
  pass=$(echo "$output" | grep -oE '[0-9]+ passed' | grep -oE '[0-9]+' || echo 0)
  fail=$(echo "$output" | grep -oE '[0-9]+ failed' | grep -oE '[0-9]+' || echo 0)
  ((total_pass += pass)) || true
  ((total_fail += fail)) || true
done

echo ""
echo "=== Total: $total_pass passed, $total_fail failed ==="
exit $total_fail

Test Harness (inline in each test-skill.sh)

Each test-skill.sh includes this minimal harness at the top — no external dependencies:

PASS=0; FAIL=0

assert_eq() {
  local desc="$1" expected="$2" actual="$3"
  if [[ "$actual" == "$expected" ]]; then
    echo "  ✓ $desc"; ((PASS++))
  else
    echo "  ✗ $desc"
    echo "    expected: $expected"
    echo "    actual:   $actual"
    ((FAIL++))
  fi
}

assert_json_eq() {
  local desc="$1" expected actual
  expected=$(echo "$2" | jq -c .)
  actual=$(echo "$3" | jq -c .)
  assert_eq "$desc" "$expected" "$actual"
}

Running Tests

# All skills
~/.claude/run-tests.sh

# Single skill
bash ~/.claude/skills/update-pr-description/tests/test-skill.sh

Since ~/.claude/ is a symlink to ~/dotfiles/claude/, the runner is also available as:

bash ~/dotfiles/claude/run-tests.sh
