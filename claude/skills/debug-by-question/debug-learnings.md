# Debug Learnings

Recurring debugging habits and gaps surfaced during question-only debugging sessions. Appended by `/debug-by-question` at the end of each session. Read by `/debug-by-question`, `/quiz-me`, `/after-pr-questions`, and `/senior-pr-questions` at startup to bias questions toward historical weak spots.

## Format

Each entry:
- **Date** — when the session ran
- **Repo** — repository the bug was in
- **Category** — Assumption-checking | Evidence-gathering | Speed
- **Bug** — short label for the bug being debugged
- **What I did** — the habit or misstep that cost time (e.g. guessed instead of reading the log)
- **What worked** — the move that finally cracked it, as reached by end of session
- **Principle** — the general debugging rule this demonstrates
